# 📦 Инструкция по деплою SurveyPro на GitHub Pages

## Проблема: Белый экран и 404

Если вы видите белый экран или ошибку 404, проблема в путях к ассетам.

## ✅ Решение

### Шаг 1: Соберите проект локально

```bash
npm install
npm run build
```

После сборки создастся папка `dist/` со всеми готовыми файлами.

### Шаг 2: Создайте репозиторий на GitHub

1. Создайте новый репозиторий (например, `survey-pro`)
2. **НЕ** инициализируйте с README

### Шаг 3: Загрузите файлы из папки `dist/`

**ВАЖНО:** Загружайте содержимое папки `dist/`, а не саму папку!

```bash
# Перейдите в папку dist
cd dist

# Инициализируйте git
git init
git add .
git commit -m "Initial deploy"

# Добавьте remote (замените username на ваш GitHub username)
git remote add origin https://github.com/username/survey-pro.git

# Запушьте в ветку main
git branch -M main
git push -u origin main
```

### Шаг 4: Настройте GitHub Pages

1. Откройте репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. В разделе **Source** выберите:
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Нажмите **Save**
5. Подождите 1-2 минуты

### Шаг 5: Откройте сайт

Ваш сайт будет доступен по адресу:
```
https://username.github.io/survey-pro/
```

## 🔧 Если всё ещё белый экран

### Проверьте консоль браузера (F12)

Откройте DevTools → Console и посмотрите ошибки:

1. **Ошибка 404 для JS/CSS файлов:**
   - Проблема: Неправильные пути к ассетам
   - Решение: Убедитесь, что в `vite.config.js` установлен `base: './'`
   - Пересоберите проект: `npm run build`

2. **Ошибка загрузки модулей:**
   - Проблема: Файлы загружены неправильно
   - Решение: Убедитесь, что загружаете содержимое `dist/`, а не саму папку

3. **CORS ошибки:**
   - Проблема: GitHub Pages блокирует некоторые ресурсы
   - Решение: Проверьте, что все файлы загружены в репозиторий

### Проверьте структуру файлов на GitHub

Ваш репозиторий должен выглядеть так:

```
survey-pro/
├── index.html
├── 404.html
└── assets/
    ├── index-XXXXX.js
    └── index-XXXXX.css
```

**НЕ** должно быть вложенной папки `dist/`:

```
❌ survey-pro/
   └── dist/
       ├── index.html
       └── assets/
```

## 🎯 Быстрая проверка

После деплоя откройте консоль браузера (F12) на странице сайта и выполните:

```javascript
// Проверьте, загружаются ли ассеты
console.log(document.querySelector('script[src*="assets"]')?.src);
console.log(document.querySelector('link[rel="stylesheet"]')?.href);
```

Пути должны быть относительными, например:
- `./assets/index-XXXXX.js`
- `./assets/index-XXXXX.css`

## 📝 Альтернативное решение: Использовать абсолютные пути

Если относительные пути не работают, измените `vite.config.js`:

```javascript
export default defineConfig({
  plugins: [react(), tailwindcss()],
  base: '/survey-pro/', // Замените на имя вашего репозитория
  // ...
});
```

Затем пересоберите и задеплойте заново.
