# 🚀 Деплой через GitHub Actions

GitHub Actions — это **лучший способ** деплоя вашего приложения на GitHub Pages.

## ✅ Преимущества

- **Автоматический деплой** при каждом push в main
- **Не нужно** вручную загружать файлы
- **Не нужно** настраивать пути
- **История деплоев** в разделе Actions
- **Откат** к предыдущей версии в один клик

## 📋 Настройка (один раз)

### Шаг 1: Включите GitHub Pages

1. Откройте ваш репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. В разделе **Source** выберите:
   - **Source:** GitHub Actions
4. Сохраните настройки

### Шаг 2: Запушьте код в main

```bash
# Убедитесь, что вы в main ветке
git checkout main

# Добавьте все файлы
git add .

# Закоммитьте
git commit -m "Setup GitHub Actions"

# Запушьте
git push origin main
```

### Шаг 3: Дождитесь деплоя

1. Перейдите в раздел **Actions** вашего репозитория
2. Вы увидите запущенный workflow
3. Подождите 1-2 минуты
4. Когда появится зелёная галочка ✅ — сайт готов!

### Шаг 4: Откройте сайт

Ваш сайт будет доступен по адресу:
```
https://ваш-username.github.io/имя-репозитория/
```

## 🔄 Как работает

```
Push в main → GitHub Actions → Сборка → Деплой → Сайт обновлён!
```

1. Вы делаете `git push` в main
2. GitHub Actions автоматически запускается
3. Устанавливает Node.js и зависимости
4. Собирает проект (`npm run build`)
5. Загружает папку `dist/` на GitHub Pages
6. Ваш сайт обновляется!

## 📊 Мониторинг деплоев

### Просмотр статуса

1. Перейдите в раздел **Actions** репозитория
2. Кликните на последний запуск
3. Вы увидите:
   - ✅ Зелёная галочка — успешно
   - ❌ Красный крест — ошибка
   - 🟡 Жёлтый круг — выполняется

### Просмотр логов

1. Кликните на запуск в Actions
2. Кликните на job (**build** или **deploy**)
3. Разверните шаги, чтобы увидеть детали

### Откат к предыдущей версии

1. Перейдите в **Actions**
2. Найдите успешный деплой
3. Кликните на него
4. Кликните **⋮** → **Re-run all jobs**

Или просто сделайте `git revert` и запушьте.

## 🐛 Решение проблем

### Ошибка: "Deploy to GitHub Pages failed"

**Причина:** GitHub Pages не включён или настроен неправильно

**Решение:**
1. Settings → Pages
2. Source: **GitHub Actions** (не "Deploy from a branch")
3. Сохраните

### Ошибка: "Build failed"

**Причина:** Ошибка в коде или зависимостях

**Решение:**
1. Перейдите в Actions → последний запуск
2. Кликните на **build**
3. Разверните шаги и найдите ошибку
4. Исправьте код и запушьте снова

### Сайт не обновляется

**Причина:** Кэш браузера или задержка GitHub

**Решение:**
1. Подождите 1-2 минуты
2. Очистите кэш: **Ctrl+Shift+R**
3. Проверьте в режиме инкогнито

### Ошибка: "Permission denied"

**Причина:** Недостаточно прав для GITHUB_TOKEN

**Решение:**
1. Settings → Actions → General
2. Workflow permissions: **Read and write permissions**
3. Сохраните

## 📝 Ручной запуск деплоя

Если нужно задеплоить без push:

1. Перейдите в **Actions**
2. Выберите workflow **Deploy to GitHub Pages**
3. Кликните **Run workflow**
4. Выберите ветку (обычно `main`)
5. Кликните **Run workflow**

## 🔧 Кастомизация workflow

### Изменить версию Node.js

Откройте `.github/workflows/deploy.yml`:

```yaml
- name: Setup Node.js
  uses: actions/setup-node@v4
  with:
    node-version: '18'  # Измените версию
```

### Добавить тесты перед деплоем

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm test  # Добавьте тесты
  
  build:
    needs: test  # Build зависит от test
    # ... остальной код
```

### Деплой только из определённой ветки

```yaml
on:
  push:
    branches: [ production ]  # Измените на production
```

## 📊 Статистика использования

- **2000 минут/месяц** бесплатно для приватных репозиториев

- **500 MB** хранилища для артефактов

Для вашего проекта это более чем достаточно!
