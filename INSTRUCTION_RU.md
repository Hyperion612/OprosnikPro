# 🇷🇺 Инструкция по деплою на русском

## 🚀 Самый простой способ (GitHub Actions)

### Шаг 1: Настройте GitHub Pages

1. Откройте ваш репозиторий на GitHub
2. Нажмите **Settings** (Настройки) вверху
3. В левом меню найдите **Pages**
4. В разделе **Source** выберите: **GitHub Actions**
5. Готово!

### Шаг 2: Запушьте код

Откройте терминал в папке проекта и выполните:

```bash
git add .
git commit -m "Деплой через GitHub Actions"
git push origin main
```

### Шаг 3: Дождитесь деплоя

1. На GitHub перейдите в раздел **Actions** (вверху)
2. Вы увидите запущенный процесс "Deploy to GitHub Pages"
3. Подождите 1-2 минуты
4. Когда появится зелёная галочка ✅ — сайт готов!

### Шаг 4: Откройте сайт

Ваш сайт будет по адресу:
```
https://ваш-username.github.io/Survey_Pro-v.2/
```

**Всё! Сайт автоматически обновляется при каждом push!** 🎉

## 🐛 Если белый экран

1. **Проверьте настройки:**
   - Settings → Pages → Source должно быть **GitHub Actions**

2. **Проверьте Actions:**
   - Перейдите в Actions
   - Кликните на последний запуск
   - Посмотрите логи (есть ли ошибки?)

3. **Очистите кэш:**
   - Нажмите **Ctrl+Shift+R** (Windows)
   - Или **Cmd+Shift+R** (Mac)

4. **Попробуйте в режиме инкогнито**
