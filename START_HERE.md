## 🚀 Как задеплоить (3 шага)

### Шаг 1: Включите GitHub Pages

1. Откройте репозиторий на GitHub
2. **Settings** → **Pages**
3. **Source:** выберите **GitHub Actions**
4. Сохраните

### Шаг 2: Запушьте код

```bash
git add .
git commit -m "Deploy with GitHub Actions"
git push origin main
```

### Шаг 3: Дождитесь деплоя

1. Перейдите в **Actions**
2. Дождитесь зелёной галочки ✅
3. Откройте сайт: `https://ваш-username.github.io/Survey_Pro-v.2/`

**Готово!** 🎉

## 🔄 Как работает автоматический деплой?

```
git push в main
    ↓
GitHub Actions запускается
    ↓
Устанавливает Node.js и зависимости
    ↓
Собирает проект (npm run build)
    ↓
Загружает на GitHub Pages
    ↓
Сайт обновляется!
```

**Никаких ручных действий!** 🚀

## 🐛 Если что-то не работает

### Белый экран?

1. Проверьте: Settings → Pages → **GitHub Actions**
2. Проверьте логи в Actions
3. Очистите кэш: **Ctrl+Shift+R**
4. См. **[CHECKLIST.md](./CHECKLIST.md)**

### Ошибка деплоя?

1. Откройте Actions → последний запуск
2. Посмотрите логи build/deploy
3. Исправьте ошибку
4. Запушьте снова
